## Notice on third-party news

The news headlines and summaries in this repository were retrieved from the Finnhub company-news API and
were written by their original publishers. They are included only so that this experiment can be
reproduced exactly, for non-commercial research. Copyright remains with the publishers and with Finnhub;
no license to the text is claimed or granted here, and it may not be reused for any other purpose.
Finnhub's free tier no longer returns part of this text, which is why it is shipped rather than
re-downloaded (see [`docs/PROVENANCE.md`](docs/PROVENANCE.md)).

## Removal requests

Rights holders who want material removed can open an issue in this repository's issue tracker naming the
files or items concerned. We will remove the material from the repository and its record archives and
note in the README which verification checks no longer apply.
